CADx Optical Diagnosis Reader Trial
This repository contains the de-identified data and R code used to reproduce the tables, figures, and additional analyses for the CADx optical diagnosis reader trial.
Data
Place the following files in the `data/` directory:
`reader responses.xlsx`: de-identified physician characteristics and reader responses.
`rjai\\\_total.xlsx`: de-identified lesion-level reference data, AI outputs, and reader responses.
`china.geojson`: geographic boundary data used for the participant distribution map.
Running the analyses
Set the repository root as the working directory. The scripts use relative paths and save generated files under `results/`.
Run `Table2\\\_TableS2.R` before `Figure2.R`, `FigureS3.R`, and `TableS5.R`, because these scripts use files generated by the Table 2 analysis. The remaining scripts can be run independently after the data files have been added.
Tables are saved to `results/tables/`, and figures are saved to `results/figures/`.
